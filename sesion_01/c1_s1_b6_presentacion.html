SESION 1.1 - AGENDA
Pregunta de apertura

Por que existen tantas bases de datos

Un archivo de hoja de calculo resuelve el almacenamiento de datos tabulares hasta cierto punto. A partir de ahi aparecen exigencias que ese formato no cubre: acceso simultaneo de varios usuarios, garantia de que una operacion se aplica de forma completa, busqueda eficiente sobre millones de registros, y control sobre quien puede leer cada dato.

Cada familia de bases de datos optimiza un conjunto distinto de esas exigencias. Ninguna las cubre todas al mismo costo.
Competencia del curso: reconocer que exigencia domina en un requerimiento dado, y seleccionar el motor en consecuencia.

SESION 1.1 - FLUJO
Motor de la sesion

SQLite: base de datos en un archivo

SQLite es un motor embebido. La base completa reside en un solo archivo y el codigo de la aplicacion la abre de forma directa, sin proceso servidor ni administracion de servicio.

CaracteristicaImplicacion practica
Motor embebidoSin instalacion ni configuracion de red
Incluido en PythonEl modulo sqlite3 viene en la biblioteca estandar
Archivo unicoLa base se copia, se versiona y se comparte como cualquier archivo
SQL estandarLo aprendido aqui aplica en PostgreSQL con ajustes menores
Escritura de un proceso a la vezNo adecuado para concurrencia de escritura alta
Es el motor correcto para iniciar el curso porque elimina toda friccion de instalacion y permite concentrar la sesion en el modelo de datos.

SESION 1.1 - DB-API
Demostracion

La secuencia minima

import sqlite3

conexion = sqlite3.connect("pagos.db")
cursor = conexion.cursor()

cursor.execute("SELECT COUNT(*) FROM movimientos")
total = cursor.fetchone()[0]
print(f"Transacciones en la base: {total}")

conexion.close()
Cuatro pasos: abrir la conexion, obtener un cursor, ejecutar la sentencia y recuperar el resultado. La misma estructura se repite en la sesion 2.1 con psycopg y una cadena de conexion distinta.
SESION 1.1 - DEMOSTRACION
Practica obligatoria del curso

Los valores se pasan como parametros

# Forma correcta
cursor.execute(
    "SELECT COUNT(*) FROM movimientos WHERE ciudad_comercio = ? AND monto >= ?",
    (ciudad, monto_minimo),
)

# Forma incorrecta: el valor se convierte en parte de la instruccion
cursor.execute(
    "SELECT COUNT(*) FROM movimientos WHERE ciudad_comercio = '" + ciudad + "'"
)
En la segunda forma, un valor construido con intencion puede alterar la sentencia ejecutada. Es el mecanismo de la inyeccion de codigo SQL, tratado a detalle en la sesion 2.1.
El taller evalua el uso de parametros. Un resultado correcto obtenido por concatenacion recibe calificacion parcial.
SESION 1.1 - PARAMETROS
Hallazgo de la sesion

Los datos llegan en una sola tabla

El extracto operativo del caso contiene quince columnas en una tabla unica llamada movimientos. Al agrupar por comercio, el resultado revela un problema:

La columna registra diecisiete valores distintos para siete comercios reales. Toda agregacion sobre esa columna produce un resultado incorrecto.
