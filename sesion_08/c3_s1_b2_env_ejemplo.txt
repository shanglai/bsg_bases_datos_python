# Sesion 3.1: variables que se agregan al archivo .env existente

#   1. Abrir el archivo .env creado en la sesion 2.1
#   2. Agregar al final las lineas de abajo
#   3. Sustituir el valor de MONGO_PASSWORD
#
# NO se crea un archivo .env nuevo. El capitulo 3 usa los dos motores
# a la vez y ambos leen del mismo archivo.
