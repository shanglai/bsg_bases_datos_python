De donde venimos

Lo que quedo abierto en la sesion 1.2

El modelo normalizado resolvio la integridad de los datos. El motor, sin embargo, conserva una limitacion: SQLite opera sobre un archivo unico y admite un solo escritor a la vez.

Pregunta de esta sesion: que ocurre cuando varias terminales registran operaciones de forma simultanea.
La respuesta implica cambiar de arquitectura. Un servidor se interpone entre los clientes y el disco, y coordina los accesos.

       SUM(v::numeric)::text AS suma_decimal
FROM (VALUES (0.01),(0.01),(0.01),(0.01),(0.01),

suma_flotantesuma_decimal
0.099999999999999990.10
Diez sumas bastan para que el error sea visible. La tabla del caso tiene cinco mil importes, y en produccion tendria millones.
Regla aplicable a todo sistema financiero: dinero en NUMERIC, nunca en punto flotante. Del lado de Python, Decimal.

SESION 2.1 - CREDENCIALES
El problema

Cuando el valor deja de ser un dato

ciudad = "Merida' OR '1'='1"

consulta = "SELECT COUNT(*) FROM pagos.comercios WHERE ciudad = '" + ciudad + "'"

Lo que recibe el motor:

SELECT COUNT(*) FROM pagos.comercios WHERE ciudad = 'Merida' OR '1'='1'
Resultado: 7 comercios. El filtro dejo de aplicarse y la consulta devuelve el catalogo completo.
Con una entrada ordinaria la concatenacion funciona. Ese es el motivo de que el error sobreviva tanto tiempo: durante las pruebas no falla.

SESION 2.1 - PARAMETROS
La solucion

El mismo valor, pasado como parametro

cursor.execute(
    "SELECT COUNT(*) FROM pagos.comercios WHERE ciudad = %s",
    (ciudad,),
)
Valor recibidoResultado
Merida1
Merida' OR '1'='10
El segundo valor se busca de forma literal como nombre de ciudad. No existe ninguna con ese nombre.
El marcador %s no es sustitucion de texto y no admite comillas alrededor. Escribir '%s' reintroduce el problema.
SESION 2.1 - PARAMETROS
Limite del mecanismo

Valores si, identificadores no

Los parametros sustituyen valores. Un nombre de tabla o de columna no puede pasarse de esa forma, porque el motor necesita conocer la estructura de la sentencia antes de recibir los valores.

from psycopg import sql

consulta = sql.SQL(
    "SELECT {campo}, COUNT(*) FROM pagos.comercios GROUP BY {campo}"
).format(campo=sql.Identifier(columna))
sql.Identifier valida y entrecomilla el nombre. Un valor arbitrario no puede convertirse en instruccion.
SESION 2.1 - IDENTIFICADORES
Carga del caso

COPY y una sola transaccion

with psycopg.connect(cadena_de_conexion()) as conexion:
    with conexion.cursor() as cursor:
        with cursor.copy("COPY pagos.transacciones (...) FROM STDIN") as copia:
            for fila in filas:
                copia.write_row((...))
COPYCarga masiva. Reduce viajes entre cliente y servidor
with connectAbre una transaccion. Confirma al salir, revierte ante error
RETURNINGDevuelve la identidad generada sin una segunda consulta
Las seis tablas se cargan dentro de una sola transaccion. Ante cualquier error, la base queda como estaba.
